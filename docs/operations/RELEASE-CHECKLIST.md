# Release checklist

- [ ] Sprint issues and milestone match the change.
- [ ] Review explains business and integration risks.
- [ ] Locked restore, format, Release build, all .NET tests, and NuGet audit pass.
- [ ] npm clean install, TypeScript build, Vitest, and npm audit pass.
- [ ] OpenAPI, UI types, and integration guide agree.
- [ ] Security and non-durable-default warnings remain accurate.
- [ ] Runbook, incident drill, migration, recovery, and rollback assumptions are reviewed.
- [ ] Changelog is complete and tag targets the green main SHA.
